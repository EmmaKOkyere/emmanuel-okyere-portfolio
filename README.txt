To preview:
1. Open index.html in a browser.
2. Keep the folder structure unchanged so links and CSS work correctly.

To publish on GitHub Pages:
1. Upload all files/folders to your repository.
2. Make sure index.html is in the repository root.
3. In GitHub: Settings > Pages > Deploy from a branch.
4. Select the main branch and root folder, then save.
